Troubleshooting

Reading the log level…

The temporary debug window asks the service to log GPU pressure decisions. When it ends, logging returns to the configured or environment filter. A service restart also ends the window. Opening or ending it asks for administrator approval.

The export saves current status, settings without credentials, the log level, the last few hours of pressure readings and the names of the programs using each GPU most. Choose where to save it, and read it before sharing.
