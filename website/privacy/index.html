Website privacy.

This is a static product website. The interactive lending illustration runs in your browser. It does not connect to your computer, inspect your hardware or control a Vacancyd service.

Website analytics

This site uses the publisher’s self-hosted Umami instance to count page visits and selected links, such as opening documentation or downloading a release. The integration excludes URL query strings and fragments. It does not send form contents, machine telemetry, inference prompts or the illustration’s presence state.

Browser privacy controls or blockers may prevent analytics from loading. The site remains usable when they do. The source shows the tracker configuration and the named link events.

External links

Downloads and source links lead to GitHub. Documentation is at docs.vacancyd.com. Those services receive normal web requests when you follow their links.
