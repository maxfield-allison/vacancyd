Run a local model. Share an inference route. Put spare resources to work when your machine can afford it.

Vacancyd sits in front of your inference server. Before borrowed work gets through, it checks owner policy, resource availability and the rules for that workload. You choose what can lend, and when.

Aware of the owner.

On Windows, the session agent reports desktop presence to the service. On Linux, systemd-logind supplies the default presence check. Dedicated machines can use headless policy.
